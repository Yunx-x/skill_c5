## 疯魔斩（0/9）

```
疯魔斩  0/9
倾力一击，状如疯魔。
猛力打击近身单个目标。

下一阶:0

单体攻击 5.1米
施法时间 1秒
真气消耗 10点
技能冷却 1秒

攻击目标1次，附加攻击力42点，
并令自身攻击增加2点，持续3秒。
可通过法宝修炼等途径提升技能级别

学习条件：
人物等级达到15级
上一修行阶段总技能等级达到2阶
需要技能点数1点
```

## 追风咒（0/5）

```
追风咒  0/5
调息内劲，轻若无骨，
追风而行，瞬息千里。
短时间内增加自身移动速度。

下一阶:

自身祝福
施法时间 1秒
真气消耗 34点
技能冷却 65秒

12秒内移动速度增加0.6米/秒，骑
乘移动速度最高不超过15米/秒；躲
闪增加2点；
若自身处于冲锋状态，则施法时间为0。
可通过法宝修炼等途径提升技能级别

*飞升前等级小于141级时，加速持续时
间延长至120秒，并增加自身非战斗状态下
移动2米/秒。

学习条件：
人物等级达到16级
疯魔斩达到1阶
需要技能点数1点
```

## 厚土咒（0/8）

```
厚土咒  0/8
五行五咒之一，困己而后伤敌，
增加自身气血上限。
「五咒·土」强命

下一阶:

被动/自身祝福
施法时间 1秒
真气消耗 110点
技能冷却 120秒

自身祝福：
16秒内削减自身受到的29%伤害，
最多不超过自身真气上限的7倍，
同时增加自身防御力800点。

被动生效:
厚土咒达到8阶，受到攻击则逐渐增
加自身的气血上限效果(在接受第一
层效果状态时，直接附加50层效果，
每层状态增加自身0.25%气血上限)；
从状态加上开始，每隔一定时间则
逐渐减少气血上限的增加效果(神佑
状态下不会减少)。

学习条件：
人物等级达到20级
疯魔斩达到1阶
需要技能点数1点
```

## 疯魔斩

**技能ID**: `待补充`

**最大等级**: 9

**技能类型**: 主动攻击

**攻击范围**: 单体攻击 5.1米

**施法时间**: 1秒

**技能冷却**: 1秒

**技能效果**:
- 攻击目标1次，附加攻击力约42点（低等级截图）
- 并令自身攻击增加（低等级截图约+2点，持续约3秒）
