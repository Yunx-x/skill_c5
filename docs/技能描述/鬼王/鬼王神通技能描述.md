# 鬼王神通技能描述

数据来源：`doc/参考/鬼王/1/神通`

## 魔魂天咒<禅>

```
魔魂天咒<禅> 20/20
原为鬼王宗长老专用法门之一，青龙初创，后经鬼王改造而成，以迅捷著称。
攻击近身目标四次。
天煞一击+5
20秒内减少目标防御，数值为自身最大攻击力。
<禅>附带增加伤害效果
<禅>一定概率中断周围玩家目标施法

群体攻击 目标周围8米
目标限制3个
施法时间2秒
真气消耗1050点
元力消耗736点
技能冷却9秒

攻击周围目标4次，附加本体攻击力125%，附加4646点攻击力，最后一击有20%概率额外附加本体攻击力1%至240%；魅惑目标3秒，魅惑能力为自身魅惑抗性加60点；并且有10%概率中断目标施法；若天煞一击成功，则2秒后追加960点伤害。
```

## 狂灵反噬<禅>

```
狂灵反噬<禅> 20/20
记载于狐歧山深层石壁的咒法，来源已不可考，且与鬼王心法相融甚洽，短时间内令自身反弹一切攻击，并免疫昏睡效果。
谨慎使用避免造成善恶值增加。
<禅>一定时间内受到伤害增加自身防御值

自身祝福
施法时间1秒
真气消耗1060点
元力消耗1900点
技能冷却180秒

20秒内100%概率反弹受到的100%伤害，同时最初10秒内免疫昏睡效果，12.0秒内受到伤害则增加相当于自身眩晕抗性0.5倍的防御，最多增加20次；技能达到20阶时增加反弹比例30%。
```

## 毁天灭地<禅>

```
毁天灭地<禅> 20/20
鬼王宗朱雀流的终极法术，虽不以劲力见长，却是宗派内少有的群体攻击手段。
攻击近身群体目标并造成伤害，并一定概率令目标一直攻击自己。
咒怨之怒+3
(嘲讽成功后，2秒后额外追加伤害)
<禅>将目标拉到身边，并减少目标吃药效果

群体攻击 自身周围13米
目标限制14个
施法时间2秒
真气消耗1250点
元力消耗1653点
技能冷却20秒

攻击自身周围目标4次，附加2000点攻击力，附加140%本体攻击力；33%概率成功嘲讽目标令其一直攻击自身；攻击怪物时额外附加20%自身气血上限的攻击力；咒怨之怒追加伤害2400点；70%概率将范围内敌对目标拉到身边，同时12.0秒内100%概率减少目标吃药效果60%。
```

## 未名斩<禅>

```

四灵血阵幻化出的戾诀，虽诞生较晚，但后来居上，超越旋龙幻杀成为鬼王宗的无上法术。
攻击近身目标六次。
「鬼王·最终奥义」
<禅>一定时间内概率令目标禁食

单体攻击 5.1米
施法时间2秒
真气消耗2250点
元力消耗826点
技能冷却13秒

攻击目标6次，附加本体攻击力127%，附加2720点攻击力；攻击怪物目标时，额外附加自身真气上限15.0%和自身防御力400%攻击力；8秒内33%概率减少自身受到的30%伤害；令目标虚弱30%，持续6秒，虚弱能力为自身虚弱抗性加40点；6秒内每一击有33%概率减少目标气血上限200%的真气值；最后一击额外附加本体攻击力15%；3.0秒内3%概率禁食目标，技能达到20阶禁食概率额外增加2%；第一、三、五击分别有10%概率清除目标身上的常规有利状态1个，第五击额外附加清除常规有利状态概率20%；第一击使得怪物目标受到的致命一击伤害增加300%，效果持续15秒。
可通过佩戴天琊法宝、传承天琊法宝等途径强化技能效果
```
